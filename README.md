# Weight Paint Master (Blender 5.0 / 5.2+ 対応アドオン)

ウェイトペイント・メッシュ編集モード・ポーズモードをシームレスに行き来し、マウスホイールによる直感的なウェイトぼかしや表示切替、ボーン管理を高速化するBlender 5.2対応アドオンです。

## 主な機能

1. **モード高速移動 ＆ ポーズ一括クリア**
   - **Poseへ飛ぶ / Weight Paint / Edit (頂点)** ボタンで、メッシュとアーマチュアを選択し直す手間なくワンクリックでモードを行き来できます（アクティブな頂点グループとポーズボーンの選択も自動同期）。
   - **ポーズをすべてクリア**: ボーンを全選択しなくても、ワンクリックでアーマチュア内の全ボーンのポーズ（位置・回転・スケール）を初期状態にリセットします。

2. **オーバーレイ ＆ アーマチュア表示切替**
   - **ウェイト等高線 (`show_wpaint_contours`)** のON/OFF
   - **ウェイトペイントのワイヤー (`show_paint_wire`)** のON/OFF
   - **編集モードのウェイト色表示 (`show_weight`)** のON/OFF
   - **アーマチュアのビューポート表示設定**:
     - **表示方法 (`display_type`)**: 八面体 / スティック / Bボーン / エンベロープ / ワイヤーフレーム
     - **名前 (`show_names`)** ON/OFF
     - **座標軸 (`show_axes`)** ON/OFF
     - **最前面 (`show_in_front`)** ON/OFF

3. **ボーン（頂点グループ）種類別フィルタ付き一覧**
   - **すべて / 選択頂点 / 変形ボーン / 中央・体幹 / 左 (`.L`) / 右 (`.R`)** の6種類のタブで頂点グループを絞り込み表示。
   - 頂点選択時には各ボーンの**平均ウェイト値**をリスト右側にリアルタイム表示。
   - **反対側切替 (`.L ↔ .R`)** ボタンで対称ボーンへ瞬時に移動。

4. **選択頂点からマウスホイールでウェイトぼかし (`Scroll Blur`)**
   - 編集モード（またはウェイトペイントモード）で頂点を選択し、マウスホイールを回すだけで直感的にウェイトをぼかせます。
   - **ホイール上下**: ぼかし反復回数 (`Steps`) の増減
   - **Shift + ホイール**: 選択頂点から周囲の隣接リングへの広がり (`Rings`: `+0` 〜 `+20`) をリアルタイム調整
   - **Ctrl + ホイール**: ぼかし強度 (`Factor`) の調整
   - **A キー**: 全頂点グループ対象（自動正規化付き）⇔ アクティブグループのみ切替
   - **X キー**: 左右対称ミラー (`X-Mirror`: `.L ↔ .R` 自動変換) のリアルタイムON/OFF切替

5. **選択頂点のウェイト数値設定・編集モード左右対称 (Xミラー)・ブラシ切替・ウェイト転送**
   - `0`, `0.1`, `0.25`, `0.5`, `0.75`, `1.0` の一括割当および `-0.1`, `-0.05`, `+0.05`, `+0.1` の相対加減算（編集モードでもそのまま動作・自動正規化連動）。
   - **X対称自動反映 (`.L ↔ .R`)**: 編集モードで頂点にウェイトを数値設定・加減算・ホイールぼかしした際、自動的に反対側の対称頂点（および反対側の `.L ↔ .R` ボーン）にも左右対称でウェイトを反映します。
   - **選択頂点を左右対称に適用 (Mirror) ボタン**: 編集モード（または標準の頂点グループ割当など）で頂点にウェイトを振ったあと、ワンクリックで選択頂点（または全頂点の `.L → .R` / `.R → .L`）のウェイトを反対側へ左右対称にミラー適用できます。
   - Blender 5.2 ブラシアセット対応の高速切替（`Mix`, `Add`, `Subtract`, `Multiply`, `Lighten`, `Darken`, `Blur`, `Average`, `Smear`）。
   - 微小ウェイト削除（`Clean`）＋影響ボーン数制限（デフォルト4ボーン）＋全体正規化の一括最適化。
   - 選択メッシュからアクティブメッシュへのワンクリック・ウェイト転送。

6. **2種類のパイメニュー**
   - **`Alt + W`**: 全機能にアクセスできる総合パイメニュー
   - **`Shift + W`**: 8方向フリックでブラシ切替・ホイールぼかし・ポーズモード移動・ポーズ全クリアを即座に実行する高速パイメニュー

## インストール方法 (Blender 5.2)

### 方法A: 単一ファイルでインストールする場合
1. Blenderの **編集 (Edit) ＞ プリファレンス (Preferences) ＞ アドオン (Add-ons)** を開きます。
2. 右上の「`∨`」アイコンから **ディスクからインストール (Install from Disk...)** を選択します。
3. `weight_paint_master.py` を選択してインストールします。

### 方法B: リポジトリのZIPでインストールする場合
1. GitHubから **Code ＞ Download ZIP** でZIPをダウンロードします。
2. Blenderの **ディスクからインストール (Install from Disk...)** からダウンロードしたZIPファイルを選択します。
